# Triathlon Periodization & Training Blocks

Structured macrocycles for Sprint and Olympic distance triathlons, 3:1 load/recovery cycles, and discipline priority shifts.

---

## 1. Multi-Sport Macrocycle Structure

- **Base Phase (8 Weeks)**: Aerobic volume in Swim/Bike/Run, basic strength, drill technique focus.
- **Build Phase (6 Weeks)**: CSS Swim threshold sets, Bike Sweet Spot/Threshold, Run Tempo & T2 Brick runs.
- **Peak Phase (3 Weeks)**: Race-pace brick sets, open-water sighting, transition speed rehearsals.
- **Taper Phase (1-2 Weeks)**: Volume reduction by $40-50\%$ across all 3 disciplines while maintaining short race-pace touches.
