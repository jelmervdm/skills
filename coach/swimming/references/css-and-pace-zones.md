# Critical Swim Speed (CSS) & Pace Zones

Operational guide for determining Critical Swim Speed (CSS), structuring swim pace zones, setting send-off intervals, and calculating swim training stress score (sTSS).

---

## 1. Critical Swim Speed (CSS) Determination

CSS represents an athlete's theoretical lactate threshold swim pace (expressed as pace per 100m or 100yd).

### The CSS Test Protocol
Perform a 400m time trial followed by a 100m time trial (with full active recovery between):

$$\text{CSS (sec/100m)} = \frac{T_{400} - T_{100}}{3}$$

*(where $T_{400}$ and $T_{100}$ are time trial durations in seconds).*

---

## 2. Swim Pace Zones

| Zone | Name | Pace Target | Purpose / Adaptations |
|------|------|-------------|-----------------------|
| **En1** | Easy / Aerobic | $\text{CSS} + 8\text{ to }15\text{s / 100m}$ | Active recovery, warm-up, body alignment drills |
| **En2** | Threshold / CSS | $\text{CSS} \pm 2\text{s / 100m}$ | Aerobic threshold, capillary density, lactate clearance |
| **En3** | VO2max / Sustained | $\text{CSS} - 3\text{ to }6\text{s / 100m}$ | Aerobic capacity, high heart rate, hard $50-100\text{m}$ reps |
| **Sp1** | Anaerobic Alactic | Maximal Sprint | Speed, power off walls, fast turnover ($12.5 - 25\text{m}$) |

---

## 3. Swim Workout Set Notation

Standard swim set formatting:
- `10 x 100m @ CSS+2s w/ 15s rest` (Interval rest)
- `10 x 100m @ 1:45 send-off` (Fixed clock send-off: if you swim 1:30, you get 15s rest)
- `4 x 200m Pull + Paddles @ En1`
