# Swim Periodization & Block Planning

Structure for pool and open-water swimming periodization, weekly volume ramp rates, and sample workout sets.

---

## 1. Swim Macrocycle Phases

- **Base Hydrodynamics**: Focus on technique, catch mechanics, kick timing, and easy En1 volume building.
- **CSS Threshold Build**: High volume of En2 threshold sets ($100-400\text{m}$ reps @ CSS pace).
- **Specialty / Open Water**: Open water simulations, sighting drills, group drafting sets, and race-pace touches.
- **Taper**: Volume reduction by $40-50\%$ over 7–10 days while maintaining short sprint touches.

---

## 2. Sample CSS Threshold Workout Set

```text
Warmup:
- 400m Easy Choice (En1)
- 4x50m Drills (Catchup, Single-Arm) w/ 15s rest
- 4x50m Build (En1 -> En3) w/ 15s rest

Main Threshold Set:
- 3x (4x100m @ CSS pace w/ 15s rest)
- 100m Easy Kick between rounds

Cooldown:
- 200m Easy Choice
```
