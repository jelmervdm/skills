# Ironman Periodization & Ultra-Distance Macrocycles

24-week periodization plan for 140.6 Full Ironman, "Big Day" simulation sessions, and 21-day taper schedules.

---

## 1. 24-Week 140.6 Macrocycle Timeline

- **Base 1 (Weeks 1-6)**: Aerobic volume building, low-intensity Z2 focus, foundational strength.
- **Base 2 (Weeks 7-12)**: Long rides up to 4.5 hours, long runs up to 2 hours, CSS swim threshold.
- **Build (Weeks 13-18)**: Long rides 5-6 hours @ 140.6 race IF, brick runs, 90g/hr gut training.
- **Peak / Big Day (Weeks 19-21)**: 6h Bike + 1h Run brick simulation (4 weeks out). Long run cap $2\text{h }45\text{m}$.
- **Taper Phase (Weeks 22-24)**: 3-week exponential volume taper (Week 22: $-25\%$, Week 23: $-45\%$, Week 24: $-65\%$).
