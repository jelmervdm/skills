# Security Policy

## Supported Versions

Security updates and patches are applied to the latest commit on the `main` / `master` branch of this repository.

| Version | Supported          |
| ------- | ------------------ |
| Main    | :white_check_mark: |

## Reporting a Vulnerability

We take the security of our skills, validation scripts, and community serious.

If you discover a security vulnerability, dangerous prompt injection vector, or code execution flaw within any skill or script in this repository, please report it responsibly:

1. **Do NOT open a public GitHub issue** for security vulnerabilities.
2. Send a private report to the maintainer via GitHub ([@jelmervdm](https://github.com/jelmervdm)).
3. Include details of the vulnerability, affected file paths, reproduction steps, and potential risk or impact.

### Response Timeline

- **Acknowledgement**: Within 48 hours.
- **Assessment & Fix**: Vulnerabilities will be evaluated and patched as soon as possible.
- **Public Disclosure**: Once a fix has been applied, public release notes will detail the patch.
